# Bog'im Gel — лендинг с заявками в Telegram и на почту

## Что изменилось в этой версии

1. **Дизайн полностью переработан** — новая типографика (Fraunces + Inter), фирменная палитра (глубокий зелёный + терракотовый + горчичное золото), авторская SVG-иллюстрация "сустав в движении" в хиро-блоке (кость плавно сгибается — анимация отсылает к теме товара), карточки, тени, hover-эффекты.
2. **Маска телефона исправлена.** Раньше при удалении цифр Backspace иногда "стирал" не цифру, а разделитель (`-`/`)`), из-за чего казалось, что цифры удаляются через раз. Теперь поле полностью управляется скриптом: хранится только массив цифр, и каждое нажатие Backspace/Delete гарантированно удаляет ровно одну цифру, независимо от курсора.
3. **Реклама `/100`, `/200`, `/300` — и вообще ЛЮБОЕ число.** Раньше для каждого числа нужно было создавать отдельную папку. Теперь этим занимается файл `404.html` (см. раздел "Как это работает" ниже) — сработает `/100`, `/205`, `/9999`, `/1` и т.д. без создания новых файлов.
4. **Подарок за полный курс.** Добавлен блок "To'liq kurs — Sustavern SOVG'A" и переключатель пакета в форме заказа (1 шт / Полный курс с подарком). Выбранный пакет уходит в заявку в Telegram и на почту.
5. **Анимации при скролле.** Блоки и кнопки красиво появляются (fade + slide/scale) при прокрутке, у главной кнопки — мягкая пульсирующая обводка. Все анимации отключаются автоматически, если у пользователя в системе включён "уменьшить движение" (accessibility).
6. Антиспам 10 минут и подписка на Telegram-канал после заявки — работают как и раньше.

## Структура файлов
```
index.html   — главная страница (открывается по обычному адресу сайта)
404.html     — служебная копия страницы для рекламных ссылок /123, /456 и т.д. (см. ниже)
style.css    — все стили
script.js    — вся логика: маска телефона, антиспам, отправка заявок, анимации

img/         — фото коробок Sustav Gel и Sustavern (webp + png-версии)
```

## Как работает reklama `/любое_число` (важно понять)

GitHub Pages — статический хостинг, там нет "сервера", который может на лету обрабатывать `/587` как что-то особенное. Но у GitHub Pages (и у большинства хостингов) есть стандартная страница **404**, которая показывается для любого несуществующего адреса — при этом URL в браузере остаётся как есть (`site.uz/587`).

Мы этим пользуемся: `404.html` — это, по сути, та же самая страница, что и `index.html`, только:
- она показывается автоматически для ЛЮБОГО пути, которого нет на сайте (`/100`, `/587`, `/12345`...),
- а `script.js` внутри неё смотрит на `window.location.pathname`, видит число в конце адреса и подставляет его в заявку как источник рекламы (`Reklama manbasi: /587`).

Благодаря этому вам не нужно создавать папку `/100`, `/200`, `/300` и т.д. вручную — **работает любое число само по себе**, сразу после публикации.

⚠️ **Важно про пути к файлам.** В `404.html` пути к стилям и скриптам прописаны от корня сайта (`/style.css`, а не `style.css`). Это нужно, чтобы страница правильно подгружала оформление, даже когда открыта по вложенному адресу вроде `/587`. Это будет корректно работать, если:
- сайт открыт по **корню домена**, например `https://sustavgel.uz/` (обычный случай при подключении своего домена к GitHub Pages), **или**
- сайт открыт как `username.github.io` (тоже корень).

Если вы публикуете сайт как GitHub Pages "страницу проекта" **без своего домена**, то есть по адресу вида `https://username.github.io/repo-name/` — тогда пути в `404.html` нужно поменять на `/repo-name/style.css`, `/repo-name/config.js`, `/repo-name/script.js` (три строки в конце файла). Обычному использованию с рекламой это не мешает, просто держите это в уме при первой настройке.

## Шаг 1. Заполните `config.js`
Откройте `config.js` и впишите:

```js
TELEGRAM_BOT_TOKEN: "ваш токен от BotFather",
TELEGRAM_CHAT_ID: "chat id вашей группы",
TELEGRAM_CHANNEL_URL: "https://t.me/ваш_канал",

EMAILJS_PUBLIC_KEY: "...",
EMAILJS_SERVICE_ID: "...",
EMAILJS_TEMPLATE_ID: "...",
```

### Как узнать Chat ID группы
1. Добавьте вашего бота в Telegram-группу.
2. Напишите в группе любое сообщение.
3. Откройте в браузере (подставив свой токен):
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
4. В ответе найдите `"chat":{"id":-100XXXXXXXXXX, ...}` — это и есть Chat ID (обычно отрицательное число).

### Как настроить EmailJS (бесплатно, без сервера)
1. Зарегистрируйтесь на https://www.emailjs.com
2. Email Services → Add New Service → подключите Gmail (или любой другой) → скопируйте **Service ID**.
3. Email Templates → Create New Template. В теле письма используйте переменные:
   `{{customer_name}}`, `{{customer_phone}}`, `{{package}}`, `{{ad_source}}`, `{{page_url}}`, получатель — `{{to_email}}`.
   Скопируйте **Template ID**.
4. Account → General → скопируйте **Public Key**.
5. Впишите все три значения в `config.js`.

## Шаг 2. Проверьте локально
Просто откройте `index.html` в браузере двойным кликом — форма, маска телефона, анимации и таймер уже работают. Реальная отправка в Telegram/почту заработает после заполнения `config.js`.

`404.html` двойным кликом открывать не нужно — он заработает только когда сайт опубликован (см. ниже).

## Шаг 3. Публикация на GitHub Pages

**Важно: у меня в этой сессии нет доступа в интернет, поэтому я не могу сам создать репозиторий и запушить код за вас — но вот точные команды, чтобы сделать это за 2 минуты.**

В терминале, в папке проекта:

```bash
git init
git add .
git commit -m "Bog'im Gel — landing"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

Дальше:
1. На GitHub откройте репозиторий → **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: **main**, папка **/(root)**.
3. Сохраните — через 1-2 минуты сайт будет доступен по адресу
   `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/`

### Если подключаете свой домен (например site.uz)
1. В настройках домена (у регистратора) добавьте A-записи на IP GitHub Pages:
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   (или CNAME на `ВАШ_ЛОГИН.github.io`, если это поддомен).
2. В Settings → Pages впишите домен в поле **Custom domain**.
3. Тогда рекламные ссылки будут выглядеть так: `https://site.uz/100`, `https://site.uz/205`, `https://site.uz/9999` — любое число.
